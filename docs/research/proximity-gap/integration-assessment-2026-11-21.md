# Proximity Prize proof assessment, 2026-11-21

Finite support-rank formulas determine the operational MCA and list-decoding thresholds for every supplied smooth code at the four prize rates. Evaluating those formulas at the two named production primes leaves several numerical endpoints open. [Universal theorem and cost](full-prize-review.md) The repository now proves the sharp half-rate MCA threshold at the boundary prime and all four MCA thresholds throughout a length-`2^30` field-budget interval. It also solves both challenges at all four rates on one length-128 code. The two named length-`2^30` prime fields have larger budgets. Lean verifies the exact rate-1/16 MCA threshold at the second named prime. The sponsor asks for the threshold of the given smooth Reed–Solomon code at rates 1/2, 1/4, 1/8 and 1/16, with constant interleaving width for the list challenge. [Sponsor statement](https://proximityprize.org/)

The boundary verification snapshot was taken on November 21 at 17:18 UTC. Subsequent results include the general rank formulas and the four-head witness on the first prime.

## What the Lean declarations establish

Let `n` be the block length, `q` the field size and `B = ⌊q/2^128⌋` the allowed count. An exact first bad error count `e` means the largest good integer error count is `e−1`. With closed Hamming balls the good real radii end just below `e/n`, so the operational supremum is `e/n` and the test fails there. The sponsor describes a largest good real radius. An account for submission should state both integer endpoints and the full real-radius predicate explicitly.
