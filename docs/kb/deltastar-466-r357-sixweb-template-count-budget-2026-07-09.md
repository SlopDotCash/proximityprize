# #466 R357 — raw six-web template enumeration is too large

At `n = 64`, the ordered `3+3` exponent family already has

```text
binom(64,3)^2 = 1,735,888,896
```

members before removing antipodal, repeated, and zero-sum degeneracies.
Quotienting only by the obvious translation, dilation, and sign-exchange
symmetries still leaves roughly `423,801` representatives.

Therefore the resultant supply route cannot enumerate every six-term template
and charge one logarithmic prime-divisor budget to each. The required
compression must use the collision web itself—e.g. a bounded number of
recurrence orbits, a transfer matrix, or an inverse theorem that groups many
templates under one arithmetic carrier. This is independent confirmation of
the R356 height obstruction.
