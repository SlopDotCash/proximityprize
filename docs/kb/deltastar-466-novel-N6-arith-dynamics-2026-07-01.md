## §1. The objects and the exact invariance (proved)

Let `p ≡ 1 (mod n)`, `μ_n ⊂ F_p^×` the order-`n` subgroup, `G_p = {j/p} ⊂ T = R/Z` the grid.

> **Definition.** `ν_b := (1/n) Σ_{x∈μ_n} δ_{(bx mod p)/p}` — a probability measure on `T`
> supported on `n` distinct grid points. For an integer `u`, `T_u : T → T, t ↦ ut mod 1`
> (the degree-`u` covering endomorphism).

**Lemma 1.1 (exact invariance).** For every integer `u` with `u mod p ∈ μ_n`:
`(T_u)_* ν_b = ν_b`, exactly. *Proof.* On the grid, `T_u(j/p) = (uj mod p)/p`; so
`(T_u)_*ν_b = (1/n)Σ_x δ_{(ubx mod p)/p} = ν_b` since `x ↦ ux` permutes `μ_n`. ∎

Hence `ν_b` is invariant under the full free-abelian semigroup generated by the least-positive
representative set `R(μ_n) ⊂ [1, p−1]` (compositions `T_u∘T_v = T_{uv}` act on the grid by
`uv mod p ∈ μ_n`). Also `ν_{ub} = ν_b`; there are `m = (p−1)/n` distinct measures, one per coset.

**Lemma 1.2 (one measure suffices).** `|ν̂_b(k)| = |η_{kb}|/n`, and as `k` runs over the nonzero
residues so does `kb`; hence `max_{k≠0}|ν̂_b(k)| = M(n,p)/n` for *every* `b`. (This is the
in-tree `lineEta_image_eq_globalImage` in measure clothing.) So WLOG `b = 1`, `ν := ν_1`, and

> **the prize ⟺ `max_{k≠0} |ν̂(k)| ≤ C·√(log(p/n)/n)` ≈ `p^{−1/8}·polylog`** — a *power* of the
> scale `1/p`.

## §6. The exact ladder: flattening coordinates = the DC-subtracted energy ladder (new bookkeeping, probe-verified)

The seed's core computation, done exactly. Let `E_r = (1/p)Σ_{k mod p}|η_k|^{2r}` (the additive

define `D_2(μ) = log(1/Σ_j μ(j)^2)/log p ∈ [0,1]`.

**Lemma 6.1 (exact coordinates).** `D_2(ν^{*r}) = (2r·log n − log E_r)/log p` for every `r ≥ 1`.
*Proof.* Grid Parseval: `Σ_j ν^{*r}(j)^2 = (1/p)Σ_k |ν̂(k)|^{2r} = E_r/n^{2r}`. ∎

**Three-regime law** (with `β = log p/log n`):

| regime | `E_r` | `D_2(ν^{*r})` | status |
|---|---|---|---|
| floor (all r) | `≤ n^{2r−1}` trivially | `≥ 1/β` | proven, trivial |
| Wick, `r < β` | `≈ (2r−1)‼·n^r` | `= r/β − log((2r−1)‼)/log p` | fixed-depth face |
| saturated, `r ≥ β` | `= n^{2r}/p·(1 + pA_r/n^{2r})` | `= 1 − log(1+pA_r n^{−2r})/log p` | **prize-blind** |

- **The per-convolution increment is exactly `1/β = 1/4`** in the Wick regime — the seed's
  `c(q)` computed: `c(2) = 1/β`, and `β` steps *exactly* close `1/4 → 1`. This is the
