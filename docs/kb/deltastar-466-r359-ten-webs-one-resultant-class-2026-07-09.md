# #466 R359 — ten collision-web orbits collapse to one resultant class

For the ten affine orbit representatives from R358, exact cyclotomic
resultant computation gives the same value in every case:

```text
Res(Φ₆₄, f_rep) = 134,227,976 = 2^3 · 16,778,497.
```

Thus the 640 genuine non-antipodal triple-sum collisions at the bad endpoint
are ten combinatorial manifestations of one arithmetic resultant class, not
ten independent prime obstructions. The common odd carrier is exactly the
endpoint prime.

This changes the global target substantially. The relevant object is a quotient
of the six-web family by equality of cyclotomic ideals/resultants. A successful
general theorem may need to bound the number of resultant classes (or their
ideal norms), which can be dramatically smaller than the number of affine
templates. Affine exponent symmetries preserve the norm; the observed equality
extends beyond the affine orbit partition and should be investigated as a
Galois/ideal-class phenomenon.
