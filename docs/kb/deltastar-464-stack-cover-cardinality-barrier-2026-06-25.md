# Issue #464: Stack Representative Cover Cardinality Barrier

Date: 2026-06-25

## Claim Tested

The floor-localization lane wants to turn a small binder/floor family into the universal incidence
input

```text
WorstCaseIncidenceBounded C delta B.
```

The only honest ways to do that are:

```text
1. prove every stack is equivalent to one of the representatives and the bad-scalar count is invariant;
2. prove every stack is dominated by one of the representatives;
3. bypass representatives and prove the universal incidence bound directly.
```

This note attacks the first option by a pure counting test.

## Formal Result

The frontier file

```text
ArkLib/Data/CodingTheory/ProximityGap/Frontier/_StackRepresentativeCoverCardinality.lean
```

now proves:

```text
if R covers all stacks and every representative fiber has size <= K,
then #WordStack <= #R * K.
```

Equivalently, if `#R * K < #WordStack`, then `R` is not a representative cover.

For the two-row MCA stacks used by `WorstCaseIncidenceBounded`, Lean also records the explicit size

```text
#WordStack(A, Fin 2, iota) = |A|^(2*|iota|).
```

It also proves the finite-action specialization.  If a proposed stack quotient is generated by a
finite family of transformations `G`, then every orbit fiber has size at most `#G`, so a cover needs

```text
|A|^(2*|iota|) <= #R * #G.
```

For a singleton binder representative, this becomes

```text
|A|^(2*|iota|) <= #G.
```

## Why This Matters

This is a direct obstruction to a common shortcut:

```text
small binder/floor list
+ domain dilation / affine reparametrization / code automorphism symmetries
=> all worst-case stacks reduce to the binder list.
```

That implication is impossible unless the transformation family is large enough to cover the full
stack universe.  Polynomial-size or visibly small symmetry groups cannot literally quotient an
exponential stack universe down to one binder profile or a tiny finite list.

## What It Does Not Rule Out

The theorem does not refute domination.  A representative can dominate many stacks without being
related to them by literal equivalence or an orbit map.  That is why the live target remains:

```text
StackDominatingRepresentativeCover
```

or a direct proof of `WorstCaseIncidenceBounded`.

## Critical Verdict

The floor route cannot close the prize by saying "symmetry should reduce to the binder stack" unless
it supplies a symmetry family whose orbit sizes are big enough on the nose.  For ordinary finite
automorphism/reparametrization families, the representative-cover route is cardinality-blocked.

The remaining plausible bridge is not a small quotient.  It must be a real sparse-domination theorem:
for every stack, the bad-scalar count is bounded above by the binder/floor representative count even
when the stack is not in the same finite orbit.
