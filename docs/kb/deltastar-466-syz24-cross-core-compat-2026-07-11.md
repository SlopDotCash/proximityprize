# SYZ24 — cross-core codeword compatibility: the honest repair of the SYZ23 leak (2026-07-11)

Issue #466 / #507. Rate-`1/2` decisive strip `(Johnson ≈ 0.293, 1/3)`.

## Context

SYZ23 (`_SYZ23DirectnessStrip.lean`) proved the correct inclusion–exclusion lower bound on the
joint syndrome span and then showed the **support-cardinality** attempt to bound the overlap
terms *leaks*: a core whose support nests inside the union of its predecessors is charged overlap
cost `0` (`crudeCost_nested`), so the support LP cannot force the joint span large enough to close
the strip. The named missing physics: **cross-core codeword compatibility** — on `C ∩ C_j` a
nested core's codeword must agree with `C_j`'s codeword, a constraint the pure `|C_i ∩ ∪C_j|`
count cannot see.

## The linear-algebra object

Per core `C_i`, `A_i := dualAnnihilator (range (evalOnS α k C_i))` = RS[α,k] dual codewords
**supported inside `C_i`**, `dim A_i = max(0, |C_i|−k)` (SYZ21 `shortening_dim`). Every `A_i` is
contained in one fixed subspace `W := A_U` = dual codewords supported in the union `U = ⋃ C_i`,
`dim W = |U|−k`. A dual codeword nesting across predecessor cores still lands in `W`: **membership
in the shortened dual code `W` is precisely the patchwork consistency the nesting demands.**

Strip needs (SYZ22 `strip_budget_of_realizability`) the **lower** bound
`finrank(⨆ A_i) ≥ |U|−k`. Cap `⨆ A_i ≤ W` gives the **upper** bound `finrank(⨆ A_i) ≤ |U|−k`.

**Verdict.** The joint span *saturates* at the ceiling `|U|−k` for **every rich (over-budget)
family** — as soon as there are `≥ |U|−k` distinct degenerate cores, `d = 0`. The additive count
`∑(|C_i|−k)` wildly over-counts (40 vs 16). I could **not** produce `d > 0` with many distinct
cores (nested, star, confined, random all give `d=0`); `d > 0` occurs **only** for sparse
(under-budget) families with too few bad scalars to threaten the strip. The saturation is the MDS
fact that the shortened dual `W` is generated by dual codewords supported in its `(k+1)`-subsets
(minimum-weight generation). **Real stacks host arbitrarily many nested cores, but their span is
capped at `|U|−k` and reaches it — nesting is not free.**

## What was proven (`_SYZ24CrossCoreCompatibility.lean`, axiom-clean)

Abstract linear algebra over SYZ23's `partialSup`, subspaces `A i ≤ W` in a fin-dim space:

1. `finrank_partialSup_le` — **the ceiling.** `A i ≤ W ∀i ⟹ finrank(⨆ A i) ≤ finrank W`. The
   true joint-span ceiling `|U|−k`; the additive `∑(|C_i|−k)` is *not* an upper bound.
2. `overlap_floor` / `total_overlap_ge` — **the repair.** Feeding the ceiling into SYZ23's
   inclusion–exclusion: `∑ finrank(A i) ≤ finrank W + ∑ overlaps`, i.e. total overlap
   `≥ ∑ finrank(A i) − finrank W`. Nested cores are **not free**: the support LP charged `0`; the
   ceiling forces the aggregate overlap up by the over-count.
3. `span_eq_ceiling_iff_generates` — **the strip direction is generation, not counting.** Under
   `⨆ A i ≤ W`, the needed lower bound `finrank(⨆ A i) = finrank W` holds **iff** `⨆ A i = W` (the
   cores generate the shortened dual). So SYZ22's opaque `union_span_rank` lower bound *is* exactly
   cross-core generation, a genuine MDS fact, provably not the overlap floor (opposite inequality).
4. `generation_delivers_span_rank` — generation + `finrank W = |U|−k ⟹ finrank(⨆ A i) = |U|−k`,
   the exact single-copy `SuperadditiveUnion.union_span_rank` value (doubled by
   `_SYZ22.doubled_shortening_dim`).
5. `span_between` — squeeze `max_i finrank(A i) ≤ finrank(⨆ A i) ≤ finrank W`.
6. Concrete: `leak_overlap_floor_val` — on SYZ23 `leakProfile64`, the repaired overlap floor is
   `∑(|C_i|−k) − (|U|−k) = 65 − 32 = 33 > 0` (vs support LP's `0`).

## Honest δ\* verdict

The support-cardinality leak is **repaired in the correct direction**: the joint-span ceiling is
`|U|−k`, forcing a positive overlap floor nested cores cannot dodge. But strip closure needs the
matching **lower** bound, which SYZ24 proves is **precisely** cross-core generation `⨆ A i = W` —
an MDS minimum-weight-generation statement the probe confirms holds for every over-budget family
but which is **not** a counting consequence. SYZ24 sharpens SYZ22's opaque `union_span_rank`
hypothesis into a concrete, probe-validated linear-algebra residual, and proves the support route
dead in both directions. **The strip does not close unconditionally; residual = MDS generation of
the shortened dual by core-supported dual codewords.** Unconditional δ\* status untouched.
