## 1. The object

Fix `n = 2^μ` (the prize uses `n = 2^30`-scale). Let `p ≡ 1 (mod n)` be prime, and let
`μ_n ≤ F_p^×` be the unique cyclic subgroup of order `n` (the smooth evaluation domain of the
Reed–Solomon code). Let `e_p(x) = exp(2πi x / p)`. Define the **Gauss periods**

```
η_b = Σ_{y ∈ μ_n} e_p(b·y),      b ∈ F_p.
```

`η_b` depends only on the coset `b·μ_n ∈ F_p^× / μ_n` (there are `(p−1)/n` of them), and
`η_0 = n`. Because `n` is even, `−1 ∈ μ_n`, so `μ_n` is symmetric and every `η_b ∈ ℝ`; the
`η_b` are exactly the eigenvalues of the **generalized Paley / Cayley graph** `Cay(F_p, μ_n)`
(`n`-regular). Set

```
B = max_{b ≠ 0} |η_b|        (the nontrivial spectral radius).
```

## 2. The target (the $1M floor)

The δ* floor in the prize window reduces (faces 1–4 of the open core, all proven equivalent
in-tree) to a **worst-case incomplete-character-sum bound**:

```
        (PRIZE)      B ≤ √(2 n ln p)        for the prize prime p = Θ(n · 2^128) ≈ 2^158.
```

This is the **Paley Graph Conjecture for the smooth subgroup `μ_n`**. The trivial bounds are
`√n ≤ B` (RMS, exact: `avg_{b≠0} η_b^2 = (pn − n²)/(p−1) ≈ n`) and `B ≤ √p` (Gauss-sum /
completion). Known *proven* results stop short:

- BGK (Bourgain–Glibichuk–Konyagin) sum-product: `B ≤ n^{1−δ}` for an unspecified tiny `δ`.
  `n^{1−o(1)}` ≫ `√(n ln p)`. **Too weak.**
- Heath-Brown–Konyagin: vacuous below `q^{1/3}` — our `n = √[β]{p}` is far below.
- Ramanujan `B ≤ 2√n` (`⟺` true Paley conjecture) is **open** and in fact *false at prize
  scale*: numerics below give `B ≈ 3.3√n`, i.e. the `√(ln p)` factor is real and unavoidable.

So the floor needs the `√(ln p)`-relaxed bound `B ≤ √(2 n ln p)` — strictly between the proven
`n^{1−o(1)}` and the (false-as-stated) Ramanujan bound.

## 3. The moment reformulation (the working object)

`B^{2r} ≤ Σ_{b≠0} η_b^{2r} =: S_r`, and by Fourier/Parseval

```
Σ_{b ∈ F_p} η_b^{2r} = p · E_r,     E_r = #{ (y_1..y_r, z_1..z_r) ∈ μ_n^{2r} : Σ y_i = Σ z_i in F_p },
        ⇒    S_r = p · E_r − n^{2r}.
```

`E_r` is the **additive energy** of `μ_n`. Choosing `r ≈ ln p` and the **Gaussian/Wick value**
`E_r ≈ (2r−1)!! · n^r` gives, after the `b=0` (DC) subtraction, `B ≤ √(2 n ln p)`. So:

> **THE WALL (one line).** Prove `S_r = Σ_{b≠0} η_b^{2r} ≤ C^r · (2r−1)!! · n^r · p` for all
> `1 ≤ r ≲ ln p`, with `C = 1+o(1)` (or any absolute `C`).

### Char-0 shadow vs. mod-p wraparound

Split `E_r = E_r^{(0)} + W_r/p` where `E_r^{(0)}` counts tuples with `Σ y_i = Σ z_i` **exactly
as algebraic integers in `ℤ[ζ_n]`**, and `W_r` counts the **mod-p wraparound** solutions where
`α := Σ y_i − Σ z_i ≠ 0` in `ℤ[ζ_n]` but `℘ | α` for the prime `℘ | p`.

- **Char-0 part is controlled (Lam–Leung).** For `n = 2^μ`, the lattice of vanishing sums of
  `n`-th roots of unity is generated by the length-2 relation `ζ^j + ζ^{j+n/2} = 0`. So
  `E_r^{(0)}` is the pure pairing/Wick count plus lower-order longer-relation corrections; it is
  `≤ (2r−1)!! n^r (1+o(1))`. **This half is, in principle, a finite/algebraic computation.**
- **Wraparound is THE wall.** `W_r` counts short (`≤ 2r` terms) `±1`-combinations of `2^μ`-th
  roots that vanish mod `℘`. A nonzero `α` with house `‖α‖ ≤ 2r` is `℘`-divisible only if its
  norm (a nonzero integer `≤ (2r)^{φ(n)}`) is a multiple of `p`. The geometry-of-numbers
  *existence* threshold `2r ≳ p^{1/φ(n)} = p^{2/n}` is **useless at prize scale** (`p^{2/n} ≈ 1`
  for `n = 2^30`), so wraparound is not excluded by size — it must be *counted*.
